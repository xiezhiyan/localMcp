# MCP 工具知识库文档

## 1. 概述

本文档是 MCP（Model Context Protocol）工具的知识库，旨在帮助 AI 模型理解和正确使用可用的工具。每个工具都包含详细的描述、参数说明、使用示例和注意事项。

## 2. 工具列表

### 2.1 add（自定义加法工具）

**工具名称**：add

**工具类型**：数学运算

**功能描述**：
执行自定义加法运算，计算规则为 `result = a + b + 3`。该工具在标准加法的基础上额外加 3，适用于需要特殊计算规则的场景。

**参数说明**：
| 参数名 | 类型 | 必需 | 说明 |
|--------|------|------|------|
| a | integer | 是 | 第一个加数 |
| b | integer | 是 | 第二个加数 |

**返回值**：
- **类型**：integer
- **说明**：计算结果 `a + b + 3`

**使用示例**：
```json
{
  "name": "add",
  "arguments": {
    "a": 1,
    "b": 2
  }
}
```
**预期结果**：6（1 + 2 + 3 = 6）

**适用场景**：
- 需要特殊偏移量的加法计算
- 测试或验证自定义计算逻辑
- 教学演示自定义运算规则

**注意事项**：
- 参数必须为整数类型
- 支持正整数、负整数和零

---

### 2.2 subtract（自定义减法工具）

**工具名称**：subtract

**工具类型**：数学运算

**功能描述**：
执行标准减法运算，计算规则为 `result = a - b`。

**参数说明**：
| 参数名 | 类型 | 必需 | 说明 |
|--------|------|------|------|
| a | integer | 是 | 被减数 |
| b | integer | 是 | 减数 |

**返回值**：
- **类型**：integer
- **说明**：计算结果 `a - b`

**使用示例**：
```json
{
  "name": "subtract",
  "arguments": {
    "a": 5,
    "b": 3
  }
}
```
**预期结果**：2（5 - 3 = 2）

**适用场景**：
- 常规减法计算
- 数值比较和差值计算
- 财务计算和统计分析

**注意事项**：
- 参数必须为整数类型
- 结果可能为负数（当 b > a 时）

**工具名称**：multiply

**工具类型**：数学运算

**功能描述**：
执行标准乘法运算，计算规则为 `result = a * b`。

**参数说明**：
| 参数名 | 类型 | 必需 | 说明 |
|--------|------|------|------|
| a | integer | 是 | 被乘数 |
| b | integer | 是 | 乘数 |

**返回值**：
- **类型**：integer
- **说明**：计算结果 `a * b`

**使用示例**：
```json
{
  "name": "multiply",
```

### 2.4 divide（自定义除法工具）

**工具名称**：divide

**工具类型**：数学运算

**功能描述**：
执行整数除法运算，计算规则为 `result = a / b`，结果为整数（整除）。

**参数说明**：
| 参数名 | 类型 | 必需 | 说明 |
|--------|------|------|------|
| a | integer | 是 | 被除数 |
| b | integer | 是 | 除数（不能为0） |

**返回值**：
- **类型**：integer
- **说明**：计算结果 `a / b`（整除，舍去小数部分）

**使用示例**：
```json
{
  "name": "divide",
  "arguments": {
    "a": 10,
    "b": 3
  }
}
```
**预期结果**：3（10 / 3 = 3，整除）

**适用场景**：
- 整数除法计算
- 分组和分配计算
- 数量平均分配

**注意事项**：
- 参数必须为整数类型
- 除数不能为零，否则会抛出错误
- 结果为整除，小数部分被舍去

## 3. 工具调用指南

### 3.1 调用格式

所有工具调用都遵循以下 JSON 格式：

```json
{
  "name": "<工具名称>",
  "arguments": {
    "<参数名>": <参数值>
  }
}
```

### 3.2 选择工具的决策树

```
用户请求 → 是否涉及数学计算？
    ├─ 是 → 需要哪种运算？
    │     ├─ 加法（含偏移量+3）→ 使用 add
    │     ├─ 减法 → 使用 subtract
    │     ├─ 乘法 → 使用 multiply
    │     └─ 除法（整除）→ 使用 divide
    └─ 否 → 无法处理，告知用户
```

### 3.3 工具选择策略

| 场景描述 | 推荐工具 | 原因 |
|----------|----------|------|
| 计算两个数的和 | add | 支持自定义加法规则 |
| 计算两个数的差 | subtract | 标准减法运算 |
| 计算两个数的积 | multiply | 标准乘法运算 |
| 计算两个数的商（整除） | divide | 整数除法，舍去小数 |
| 需要特殊计算规则 | add | add 工具包含额外偏移量 |
| 平均分配物品 | divide | 整除特性适合分组 |

## 4. 错误处理指南

### 4.1 常见错误类型

| 错误码 | 错误类型 | 说明 | 解决方法 |
|--------|----------|------|----------|
| -32602 | Invalid params | 参数无效或缺失 | 检查参数是否完整且类型正确 |
| -32601 | Method not found | 方法不存在 | 检查工具名称拼写是否正确 |
| -32700 | Parse error | JSON 解析错误 | 检查 JSON 格式是否正确 |
| -32600 | Invalid Request | 请求格式无效 | 检查请求结构是否正确 |

### 4.2 特殊错误处理

**除零错误**：
- 当使用 divide 工具时，如果除数为零，会抛出 `ArithmeticException`
- 建议在调用前验证除数不为零

## 5. 使用示例场景

### 场景1：计算购物总价

**需求**：购买 3 件商品，每件 5 元，使用优惠券减 10 元，最终支付多少？

**步骤**：
1. 使用 multiply 计算商品总价：3 * 5 = 15
2. 使用 subtract 计算优惠后价格：15 - 10 = 5

```json
[
  {"name": "multiply", "arguments": {"a": 3, "b": 5}},
  {"name": "subtract", "arguments": {"a": 15, "b": 10}}
]
```

### 场景2：分配物品

**需求**：将 100 个苹果平均分给 7 个人，每人能分到几个？

**步骤**：
1. 使用 divide 计算每人分到的数量：100 / 7 = 14（整除）

```json
{"name": "divide", "arguments": {"a": 100, "b": 7}}
```

### 场景3：特殊计算

**需求**：计算两个数的特殊和（含偏移量）

**步骤**：
1. 使用 add 计算：5 + 8 + 3 = 16

```json
{"name": "add", "arguments": {"a": 5, "b": 8}}
```
